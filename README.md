# CoForge
> Real-time collaborative workspace sharing and synchronization for Visual Studio Code.

CoForge is a Visual Studio Code extension designed to make collaborative development easier by allowing developers to create and join shared coding sessions directly from VS Code.
Instead of manually sharing project files or using external collaboration tools, CoForge provides a workspace-oriented collaboration system where users can connect through a shared session and work with the same project structure.

---

## 🚀 Features

### 👥 Collaboration Sessions
Create a collaboration session and share the generated session ID with other developers.

```text
User A
  │
  ├── Start Collaboration
  │
  ▼
CoForge Server
  │
  └── Session ID
       │
       ▼
     User B
  Join Session
```

Each collaboration session has a unique session ID.
Example: `dcc4ca4e-26ba-4269-833e-318f9c2f4633`

### 🔗 Join Existing Sessions
Other developers can join a session using the session ID generated by the host.
`CoForge: Join Collaboration`
Once connected, the client communicates with the collaboration server and joins the existing workspace session.

### 📁 Workspace Snapshot
When a user joins a collaboration session, CoForge can synchronize the workspace structure and files from the host.
This allows the joining user to obtain the project files required for the collaboration session.

### 🔒 File Locking
CoForge uses file-level collaboration control to reduce editing collisions.
When a user is actively working on a file, another collaborator can be prevented from modifying the same file.

### 🗂️ File Management
CoForge supports collaborative workspace file operations including:
- File creation
- File deletion
- File renaming
- Directory structures
- Workspace synchronization

### 🔄 Reconnection and Resynchronization
CoForge includes reconnection and workspace resynchronization mechanisms.
If a client temporarily loses its connection, the extension can reconnect to the collaboration server and synchronize the workspace state again.

### 🌐 Production WebSocket Server
CoForge communicates with its production collaboration server through WebSockets:
`wss://coforge.onrender.com`

---

## 🏗️ Architecture
CoForge consists of two major components:

1. **VS Code Extension**
Responsible for VS Code integration, workspace interaction, session management, WebSocket communication, file operations, snapshot handling, file locking, and reconnection.
2. **Collaboration Server**
Responsible for WebSocket connections, session creation/joining, client management, session registry, message validation, workspace synchronization, and file operation coordination.

## 🔌 Communication Flow
**Starting a Session**:
Host -> `CoForge: Start Collaboration` -> WebSocket Connection -> `CREATE_SESSION` -> `SESSION_CREATED` -> Session ACTIVE

**Joining a Session**:
Collaborator -> `CoForge: Join Collaboration` -> WebSocket Connection -> `JOIN_SESSION` -> `SESSION_JOINED` -> Workspace Snapshot

## 🧪 Testing CoForge Locally
The recommended way to test two users on one computer is to use two separate VS Code windows with separate workspaces.
1. Create a `Host` and `Client` folder.
2. Open `Host` in VS Code 1, `Client` in VS Code 2.
3. User A runs `CoForge: Start Collaboration`.
4. User B runs `CoForge: Join Collaboration` with the session ID.

---

## ⚠️ Current Limitations
CoForge is currently under active development.
The core collaboration infrastructure, session creation, session joining, workspace sharing, file management, file locking, and reconnection/resynchronization are fully functional.
**However**, live text synchronization is still being refined. Rapid simultaneous text editing may not yet provide the perfectly smooth, conflict-free experience expected from mature collaborative editors (like Google Docs).
CoForge should therefore currently be considered a collaborative workspace/session system with synchronization capabilities, rather than a fully CRDT/OT-based real-time editor.

## 🛠️ Development

**Install Dependencies:**
```bash
npm install
cd server
npm install
```

**Build the Extension:**
```bash
npm run compile
```

**Package the Extension:**
```bash
npm install -g @vscode/vsce
vsce package
```
Install locally: `code --install-extension .\coforge-x.x.x.vsix --force`

**Production Server:**
Development:
```bash
cd server
npm run dev
```
Production build:
```bash
npm run build
npm start
```
